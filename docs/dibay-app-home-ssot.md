# DIBAY 앱 홈 — 단일 정의 (홈 시안 v4 · Owner 「이 시안으로 진행」 2026-11-14)

> 이전 판: 홈 시안 v22 (Owner 「이대로 구현」 2026-11-09). 시안: `docs/design/home-lounge-label-mockup-2026-11-14.html` §4.

## 0. 왜 홈인가 (3가지만 — 해당하지 않는 칸은 넣지 않는다)

| 목적 | 칸 |
|---|---|
| ① 서비스 입구 (핵심 = telRING) | 서비스 입구: telRING 대표 칸(채팅·통화 바로가기) → 큰 칸(마켓·DIPICK) → 작은 아이콘(정보 공유·모임·이벤트) |
| ② 운영자 소식 | 어드민 배너(「광고」 표기 가능) · 공지 한 줄(→ 고객센터 공지사항 목록) |
| ③ 지금 동네에서 볼 거리 | 「지금 우리 동네」 — 마켓 상품·정보 공유 글(인기순)·DIPICK 매장·모임을 섞은 한 줄기 피드 |

- 검색창 없음 (통합검색 = 라운지 머리글 검색 아이콘). 개인 정보 칸 없음 — 지역이 같으면 모두 같은 화면, 개인 숫자는 머리글 종·하단 탭 배지만.
- 칸 순서는 코드 고정(`HOME_SECTION_KEYS`), 어드민은 보이기·피드 제목·피드 구성(마켓·정보 공유·DIPICK 탭)만.
- 옛 칸(진행 중 배달·배달 업종 줄·매장 칸·거래 줄·교민 이야기·작은 바로가기)은 v4 에서 뺐다. 저장값의 옛 칸은 무시한다.
- 피드 배너 광고(3:1)는 홈 광고 자리(재고) 결정 전이라 아직 없다 — Owner 결정 필요.

## 2. 화면 (위 → 아래)

1. **상단**: 밝은 바탕 · dibaY 로고 → 오른쪽 주소(회원 = 대표 배달 주소, 비로그인 = 전체 지역) · 맨 오른쪽 검은 종(배지 약 30% 겹침) / 비로그인 = 「로그인」.
2. 당겨서 새로고침 슬롯(커뮤니티와 같은 공통 슬롯 · 시그니처 그린) → 큰 둥근 검색창.
3. 어드민 「홈 구성」 칸 (순서·보이기·비로그인 보이기·칸 제목 모두 어드민):
   - **배너**: 바탕 위 이미지 + 제목·내용 (카드 없음). 비율 1:1/4:3/3:4/16:9 · 크기 24/30/38%(96~220px) · 좌우 · 제목 크기 15/16.5/19px · 대상(전체/회원/비로그인) · 「광고」 표기.
   - **진행 중 배달**(회원만, 있을 때만 한 줄).
   - **서비스 카드**: 큰 카드(거래·배달) = 제목 + 설명 줄 + 그림, 작은 카드(정보교환·채팅·이벤트) = 제목 + 설명 줄. 색 칸·이모지 없음. 설명 자동 = 거래 카테고리·매장 업종에서.
   - **배달 업종 줄**: 업종 그림 한 줄 가로 넘김(또는 두 줄). 누르면 `/stores/browse/업종`.
   - **우리 동네 배달 매장**: 매장 머리줄(상태 문구) + 메뉴 사진 가로 넘김, 「매장 보기 ›」.
   - **방금 올라온 거래**: 사진 가로 넘김.
   - **교민 이야기**: 정보교환 게시판 목록과 같은 카드(`CommunityCard`).
   - 작은 바로가기(기본 끔).
4. **홈은 요약만** — 칸 제목 옆 「더보기 ›」·「전체 ›」 없음 (Owner 2026-11-09). 각 항목을 누르면 그 화면으로 간다.
5. **하단 메뉴** — 아래로 스크롤하면 숨김, 1.8초 멈추거나 위로 스크롤하면 다시 보임(공통 규칙표 `use-bottom-nav-scroll-hide-behavior.ts` 홈 = on). 맨 아래 여백은 앱 셸의 하단 메뉴 여백 하나만(홈 자체 여백 없음).
6. 글자 = 네이버 홈 비율(배너 제목 16.5·600, 칸 제목 16·600, 상품 이름 14, 가격 15·700). 글자체 = 앱 기본 Pretendard.

## 3. 매장 칸 — 지역·판정·교체

- 후보 매장 = 배달 탭 홈 피드 `GET /api/stores/home-feed` 결과 그대로 (배달 가능 → 같은 동네 → 가까운 거리 → 주문 많은 → 평점). 배달 판정은 `evaluateDeliveryServiceArea` 하나 — 홈에서 따로 판정하지 않음.
- 보이는 조건: 배달 켬 · 회원 대표 주소가 배달 지역 안. **영업시간 밖·샘플 매장도 보인다**(Owner 2026-11-09) — 영업 중 먼저, 매장마다 배달 탭과 같은 상태 문구(영업 중·휴식 중·영업 종료·준비 중). 어드민 「직접 고르기」(후보 최대 20) 또는 「자동」(업종·최근 주문·새로 연 순).
- 메뉴 = `GET /api/home/store-menus` (판매 중 · 검수/숨김 구역 제외 · 사진 있는 메뉴, 대표 → 사장님 추천 → 정렬 순서, 어드민 직접 고른 메뉴 우선).
- 비로그인 = 로그인 안내(S-07) · 대표 주소 없음 = 주소 등록 안내 · 0곳 = 한 줄 안내.
- 메뉴·＋ 누르면 `/stores/매장/p/메뉴`(담기는 그 화면). 홈에서 담기 시트를 직접 열지 않는다 — 장바구니·담기 시트는 배달 화면 안에서만 마운트되는 기존 계약.
- 샘플 매장(`store_kind=sample`)은 배달 탭처럼 「샘플」 표시, 주문은 기존 게이트가 막음.

- 순서: 직접 고르기 = 어드민이 고른 순서 · 자동 = 영업 중 먼저, 그다음 배달 탭 순서.
- 불러오기 실패는 「불러오지 못했어요 · 다시 시도」로 보이고 「없음」으로 바꿔 보이지 않는다. 실패는 교체 기록에 넣지 않는다.

## 4. 바뀌는 때 (교체)

- 당겨서 새로고침 · 재접속(새 세션)만. 홈을 보는 동안·탭 갔다 오기·뒤로 가기로는 안 바뀜.
- 「한 번도 안 나온 것 먼저 → 가장 오래전에 나온 것」 — 배너(어드민 순서로 한 바퀴)·매장·매장별 메뉴·거래. `lib/home/home-rotation.ts`.
- 거래 후보 = 판매중·예약중 글(최근 7일 글 먼저, 모자라면 오래된 글로 채움), 지역 = 거래 탭에서 이번 실행에 고른 지역(없으면 전체 지역).

## 5. 어드민 「홈 구성」

- `/admin/menus/home-layout` (조회 전원 · 저장 `settings`). API `GET/PUT /api/admin/home-layout`, 이미지 올리기 `POST /api/admin/home-layout/upload`, 매장 찾기·메뉴 목록 API.
- 저장: `admin_settings` 키 `home_layout` (schemaVersion 2). 읽은 판(`updated_at`)과 다르면 **409** 로 멈춤, 읽기 오류면 **503**. 저장 시 캐시 태그 `home-layout` **즉시 만료**(`expire: 0`). DB 읽기 실패 결과는 캐시하지 않는다.
- 링크: 앱 안 경로만(`//`·역슬래시·제어문자 거절, 같은 사이트로 풀리는지 확인). 이미지: `/images/…` 또는 어드민 올리기 공개 버킷 주소만.
- 모양·기본값·검증: `lib/home/home-layout-contract.ts`. 링크는 앱 안 경로만.
- 배너 이미지 규격: 1:1 720×720(최소 480) · 4:3 960×720 · 3:4 720×960 · 16:9 1280×720, PNG/WebP/JPG 2MB, 비율 ±2% 밖이면 거절. 카드 그림 330×330 이상 정사각.
