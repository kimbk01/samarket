통화 버튼 통합 — 감사 · 설계안 · 시안 (2판)

작성 2026-11-12 PHT · 기준 코드 origin/main 67d6b629a · 범위: 1:1 · 그룹(통화 보류) · 거래 · 주문 채팅방의 통화 시작, 그리고 통화 내역(통화 탭 · 방 안 통화 기록) · 코드 감사·설계만 — 코드 변경 없음 · 실기기·운영 화면 미확인

1판에서 틀린 점 (먼저 정정)
  • 1판은 헤더에 🎥 아이콘을 하나 더 붙이는 안이었습니다. 화면 폭이 좁은 기기에서 이름이 잘리는 문제를 따지지 않았고, Owner 가 원한 「전화 아이콘 하나 → 통화 방식 선택」 형태가 아니었습니다.
  • 이미 저장소에 같은 형태의 선택 시트(MessengerContactsCallChoiceSheet — 「DIBAY 음성 통화 · DIBAY 영상 통화 · 휴대폰 전화」, 번호 없으면 회색)와 Owner 원문 「통화시 일반 전화가 되냐?? 디바이 통화가 되느냐를 설정」(docs/design/messenger-contacts-sync-plan.md:9)이 있는데 1판에서 확인하지 않았습니다.
  • 2판은 이 기존 시트·계약을 기준으로 다시 설계했습니다.

1. Owner 지시 (원문 기준)

  1. 아이콘을 늘리지 않는다 — 기기별로 헤더가 잘린다.
  2. 전화 아이콘 하나를 누르면 음성 · 영상 · 일반 전화 중에서 고른다.
  3. 친구 관리(연락처 동기화)로 상대 전화번호가 있으면 일반 전화 활성, 없으면 회색 비활성.
  4. 통화 내역에서는 그 기록의 통화 종류로 다시 건다.
  5. 중복 위치 없이, 각 채팅방에서 정확한 통화가 걸린다.

4. 설계안

규칙 하나: 「📞 하나 → 선택 시트 → 바로 연결」
  1. 위치: 방 안 통화 시작은 헤더 오른쪽 📞 하나뿐. ⋮ 메뉴의 「음성 통화」「영상 통화」, 방 안 프로필 시트의 통화 버튼, 주문 진행 시트의 📞 는 없앰.
  2. 📞 를 누르면 선택 시트 (기존 연락처 선택 시트와 같은 모양·같은 문구):
    • 「DIBAY 음성 통화」 — 무료 · 데이터
    • 「DIBAY 영상 통화」 — 무료 · 데이터
    • 「휴대폰 전화」 — 이 기기 연락처에 상대 번호가 있으면 활성(통신사 요금 · 이 기기 번호), 없으면 회색(이 기기에 번호 없음)
    세 줄은 항상 같은 자리에 보임. 방 규칙으로 막힌 DIBAY 줄은 회색 + 짧은 이유(예: 「판매자가 음성만 허용」 「매장이 영상 통화를 받지 않음」 「통화를 연결할 수 없어요」).
  3. 고르면 바로 연결 — 시트에서 고른 것이 확인 역할을 하므로 확인 팝업을 한 번 더 띄우지 않음 (연락처 회원 시트가 이미 이렇게 동작: startContactsDibayCall). DIBAY 발신은 지금과 같은 함수 startManagedDirectCall(방 발신 · 매장명 표시 그대로).
  4. 진행 중 통화가 있으면 📞 는 시트 없이 그 통화 화면으로 (지금 헤더 동작을 모든 진입점에 동일).
  5. 📞 자체를 숨기는 경우: 그룹(보류) · 거래 글 통화 「허용 안 함」 · 매장이 음성·영상 둘 다 끔 — 지금 노출 규칙 그대로 (방 통화 규칙을 바꾸지 않음).
  6. 통화 내역: 통화 탭 줄 오른쪽 아이콘과 방 안 통화 기록 말풍선은 그 기록의 종류(음성/영상)로 다시 걸기 — 지금처럼 확인 팝업 1번 (목록에서 잘못 누름 방지). 방 안 말풍선은 헤더와 같은 판정을 써서 막힌 종류·그룹은 눌리지 않는 모양. 통화 상대 상세 초록 띠에 「휴대폰 전화」 칸 추가 (번호 없으면 회색).

6. Owner 확인이 필요한 충돌 (허위 보고 금지 7번 — 임의로 고르지 않음)

#충돌설계안의 처리
K1연락처 정책 #12 「다른 기기에서만 발견된 회원 → 휴대폰 전화 숨김」(messenger-contacts-sync-plan.md:45) vs 이번 지시 「번호 없으면 회색」방 시트·통화 상대 상세는 이번 지시대로 회색. 연락처 회원 시트(#12 대상)는 바꾸지 않음.
K2연락처 기본 통화 방식 설정(C2: 매번 묻기 · DIBAY · 휴대폰)은 지금 연락처 회원 시트와 홈 친구 「음성」에만 적용방 헤더는 이번 지시대로 항상 선택 시트 (설정을 적용하지 않음). 설정을 방에도 적용하려면 별도 지시 필요.
K3주문 채팅의 「휴대폰 전화」 번호를 매장 공개 전화번호(매장 상세에 이미 공개)·주문 구매자 번호(사장님 주문 카드에 이미 표시)로 채울 수 있음 — 지시는 「친구 관리로 등록된 번호」지시대로 이 기기 연락처 번호만 사용. 매장·주문 번호 사용은 넣지 않음.
K4거래 통화 시작 권한 — 옛 거래 화면 코드(ChatDetailView.tsx:601, 지금 도달 불가)는 구매자만, 현재 메신저 거래방·서버는 판매자·구매자 모두현재 동작(모두) 유지.
