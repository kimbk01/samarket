### 2-1. 주제별 세부 필터 (운영 DB 주제 6개 · 코드 해석기 값)
| 주제 | 세부 칸 |
|---|---|
| 중고거래 | 없음(공통 칸만) |
| 중고차 | 삽니다/팝니다 · 제조사 · 모델(고른 제조사 것만) · 차종 · 변속기 · 연료 |
| 부동산 | 거래 유형(임대·판매) · 부동산 유형(상가·주택·콘도·주차장) |
| 환전거래 | 환전 방향(페소 팝니다·삽니다) |
| 일자리 | 구인/구직 · 업종 · 근무 형태 · 급여 유형 |
| 렌터카 | 제조사 · 모델 · 변속기 · 연료 |
- 모든 칸은 기본값 「전체」다. 자동 선택은 없다.
- 구성에 「필터」로 표시돼 있지만 화면에 없는 범위 칸(연식·주행거리·방·욕실·면적·보증금·월세·급여·환율·금액·일일 요금·기사 포함)은 **이번 범위에서 제외**한다. Owner 요청에 없다.

### 2-2. 찾기 구간 정의 (목록계약 §3① 개정 — 승인 대상)
1. 같은 물품 = 모든 단어 일치(지금 계약).
2. 비슷한 물품 = 단어 하나 이상 일치, 맞은 단어 수가 많은 순.
3. 같은 주제의 다른 물품.
4. 나머지.
- 운영 DB 결과와 한계(짧은 단어가 관련 없는 글을 끌어옴, `motorcycle` 0건)는 화면 설계 문서 §3-2 표를 그대로 따른다.
