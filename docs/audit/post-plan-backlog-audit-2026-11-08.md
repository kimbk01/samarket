## 2. 원인·설계안

### B-1 휴대폰 앱 「브라우저 알림」 줄 (묶음 1)

- **원인:**
  - `NotificationsSettingsContent.tsx:400` 이 줄을 조건 없이 그린다.
  - 숨김 규칙(`shouldHideWebPushSettingsRow`)은 Windows 앱·서버 꺼짐만 본다.
  - 휴대폰 앱 화면(WebView)은 웹 푸시를 지원하지 않는다. 그래서 서버에서 켜면 「이 브라우저에서는 알림을 받을 수 없어요」와 눌리지 않는 버튼이 나온다.
- **설계:**
  - 규칙에 「휴대폰 앱(`isCapacitorNativePlatform`)이면 숨김」을 추가한다(Windows 판정과 같은 하이드레이션 안전 방식).
  - 테스트 1건을 추가한다.
- **영향:** 휴대폰 앱 알림 설정. 지금은 이미 숨겨져 있어 화면 변화는 없다(서버 꺼짐).

### B-2 공용 개발 폴더 라이브러리 (묶음 0 · 환경)

- **원인:** `samarket/node_modules` 는 `qrcode`·`jsqr` 추가 전에 설치된 상태다.
- **설계:** 공용 폴더에서 잠금 파일대로 `npm install` 을 1회 실행한다.
  - 다른 세션이 그 폴더를 쓰고 있을 수 있다.
  - 그래서 Owner 승인 후, 실행 중인 세션이 없을 때 한다.
- **영향:** 운영 무관.

### B-3 앱 로그인 활성 세션 쿠키 누락 (묶음 1 · 인증 잠금 재개방 트리거 3)

- **원인:**
  - `app/api/auth/native/exchange/route.ts:93-94` 가 임시 응답을 로그인 처리에 넘긴다.
  - 카카오·Google·Apple 처리(`*-native-session.server.ts`)는 `syncActiveSessionForUser(…, ctx.response)` 로 그 임시 응답에 `samarket_active_session_id` 를 쓴다.
  - 그런데 `:123` 에서 응답을 새로 만들고 `:137` 에서 Supabase 쿠키만 옮긴다.
  - 탈퇴 회원 거절 응답(`:113`)에도 쿠키 삭제가 옮겨지지 않는다.
- **재현:** 실제 `setActiveSessionCookie` 를 쓰는 테스트에서 최종 응답에 활성 세션 쿠키가 없다(작업자 실행 PASS = 누락 확인).
- **사용자 영향 (코드 추적 — NOT_PROVEN):**
  - 로그인 직후 앱 부팅이 `GET /api/me/profile` 을 부르고, 거기서 같은 세션 번호로 쿠키를 다시 심어 **스스로 복구**된다.
  - 다만 그 전에 엄격한 쓰기 API(약 40개 — 예: 채팅 전송)가 먼저 불리거나 부팅 요청이 실패하면 401 「로그인이 필요합니다」가 날 수 있다.
  - 웹 OAuth·PC QR·비밀번호 로그인은 정상이다(같은 응답에 쓰거나 운반 응답을 옮김).
- **설계:**
  - 임시 응답을 「운반 응답」으로 두고, 성공(`:123`)·실패(`:113`) 최종 응답에 그 쿠키를 모두 옮긴다. PC QR 상태 라우트·`logout/route.ts` 와 같은 방식이다.
  - 라우트 테스트를 추가한다: 200 에 활성 세션 쿠키, 탈퇴 403 에 삭제 쿠키.
- **영향:** 앱 로그인 API 1곳(웹 코드). 네이티브·통화 코드 무변경. 인증 잠금 재개방(트리거 3 — 코드 결함, 테스트 재현) **승인 필요**.

### B-8 PC 진행중 거래 탭 줄 (묶음 1)

- **원인:**
  - 탭 줄(`components/mypage/products/MyProductFilter.tsx:62`)은 화면 전체 폭에 그려진다.
  - 그런데 PC 헤더 정렬 규칙(D2)은 제목 줄만 본문 열에 맞춘다.
  - 같은 구조인 거래 허브 탭(`TradeHubTopTabs.tsx:80`)은 본문 열 틀(`APP_MAIN_COLUMN_CLASS`)로 감싸 정렬이 맞다.
- **설계:** 탭을 같은 본문 열 틀 + 좌우 여백으로 감싼다. 배경·밑줄은 전체 폭을 유지한다.
- **영향:**
  - PC·태블릿(768px+)에서 탭이 가운데 열로 온다. 거래 허브 탭과 같다.
  - 휴대폰은 화면이 열보다 좁아 변화가 없다.
- **보고만:** 같은 방식의 다른 탭(`MarketplaceSellHubPills`·`HomePurchaseSalesHubTabs`)은 조사하지 않았다. 후속 목록 B-16 으로 추가한다.
