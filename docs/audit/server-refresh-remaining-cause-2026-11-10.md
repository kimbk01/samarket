## 2. 아직 확인 못 한 것 (NOT_PROVEN)
- 다시 불러온 새 문서 뒤의 요청들이 **왜 아직 만료 쿠키를 들고 갔는지**. 문서 요청에서 proxy 가 갱신하면 응답 `Set-Cookie` 로 새 토큰이 와야 한다. 후보 — (가) iOS WKWebView 에서 응답 쿠키가 바로 다음 요청에 반영되지 않음 (나) 다시 불러오기 직전 옛 화면이 이미 보낸 요청 (다) 그 밖. 서버 로그에 요청 경로·쿠키 상태가 남지 않아(런타임 로그는 앱이 찍은 줄만, Vercel 요청 단위 지표는 이 프로젝트에 수집 안 됨) **요청 1건 단위로 가리지 못했다**.
- 지역별로 어느 구성요소인지(싱가포르·한국 = proxy, 인도 = 페이지·API 함수로 보이지만 IP 만으로는 단정 불가).
- 남은 39건(작은 묶음·단건)의 경로.
