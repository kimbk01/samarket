# 확인창 문구 통일안 — 「행동에 대한 질문 한 줄」 (승인 요청 · 2026-11-02)

- 기준 (Owner 2026-11-02): 확인창은 **사용자가 하려는 행동을 짧게 묻는 질문 한 줄**이다. 설명 문장을 붙이지 않는다.
- 대상: 앱 확인창 전수 (관리자 화면 제외). 코드에서 호출처 120곳을 뽑아 실제 문구(한국어)를 하나씩 확인했다.
- 제외: 통화(발신 확인 · 통화 기록 삭제 — 통화 규정), 라이더(없는 기능), 입력창 3종은 질문이 아니라 입력 요청이라 아래 §4 에 따로.
- **아직 아무것도 바꾸지 않았다.** 승인받은 뒤 이 표대로만 바꾼다.

## 1. 통일 규칙 (5개)

1. 제목 = **「(대상)을/를 (행동)할까요?」 한 줄**. 설명 줄 없음.
2. 버튼 = **[취소] [행동 동사]**. 왼쪽은 항상 「취소」. 오른쪽은 제목의 동사 그대로 (삭제할까요? → 「삭제」).
3. 명사 제목(「카테고리 삭제」「배너 삭제」「진행 단계 변경」)은 질문으로 바꾼다.
4. 「~하시겠습니까?」「~하시겠어요?」「정말 ~」 → 「~할까요?」.
5. 이름·금액 같은 **값은 질문 안에** 넣는다 (「{이름}님을 차단할까요?」). 값 말고 설명은 넣지 않는다.
