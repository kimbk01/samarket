## 0. 사전 확인 (하나라도 다르면 중단하고 보고)

1. **배포 확인:** Production(samarket.vercel.app)이 main `4e84e33c` 이상인지 Vercel 에서 **1회만** 확인한다. 반복 확인은 하지 않는다. 확인할 수 없으면 NOT_PROVEN 으로 기록하고 계속한다.
2. **앱 재시작:** 세 기기 모두 앱을 **완전히 종료한 뒤 다시 실행**한다. 웹 변경은 재시작만으로 반영된다.
3. **설치 버전:** 운영 DB `public.user_devices.app_version` 을 읽기 전용으로 조회한다.
   - Samsung·Xiaomi 는 `1.2.4 (9)` 또는 `1.2.4 (10)`, iPhone 은 `1.2 (7)` 이어야 한다.
   - 그보다 오래된 바이너리면 결과를 무효로 처리한다. (10) 은 카카오 로그인만 다르므로 통과로 본다.
4. **계정:**
   - A = Samsung 폰, B = iPhone 14 Pro Max, C = Xiaomi 태블릿. 서로 다른 계정이다.
   - A·B 는 서로 친구이고 1:1 방이 있다. A·C 도 1:1 방이 있다.
   - 주문 채팅 1개(진행 중), 거래 채팅 1개를 준비한다.
5. **로그 수집 (Android):**
   ```
   adb -s <serial> logcat -v epoch | grep -E "DIBAY_CALL_CORR|DIBAY_CALL_V4|cm-rt|call-push|Capacitor/Console"
   ```

6. **기록 형식 (항목마다):** 기기·버전 / 계정 / 단계 / 기대 / 실제 / **PASS·FAIL·NP** / 증거(스크린샷·logcat·DB 조회 1줄).

7. **금지:** 테스트 DB(`dibay-test`·`dibay-reset-qa`) 접근 금지. 운영 DB 는 **읽기 전용 조회만** 한다. 코드는 수정하지 않는다. FAIL 이 나오면 재현 조건과 로그만 보고한다.

## 5. 통화 상태·경고 팝업 (3부 T·U절) — 이번 핵심

> **팝업 기준:**
> - 위치는 **화면 중앙 공통 팝업**(아이콘·제목·설명·[닫기]·[다시 걸기]). 하단 토스트가 아니다.
> - 같은 실패에 팝업은 1번만 뜬다.
> - 닫으면 다시 뜨지 않는다.
> - 네이티브 통화 화면(앱 영상·음성 화면)이 떠 있는 동안에는 기존 네이티브 안내가 나올 수 있다(⑤ 대상). **팝업 판정은 통화 화면이 닫힌 뒤 웹 화면 기준**으로 한다.

**DB 증거 (읽기 전용, 테스트 후 1회):**
```sql
select l.status, l.ended_reason, l.duration_seconds, l.created_at
from community_messenger_call_logs l
where l.created_at > now() - interval '2 hours'
order by l.created_at desc
limit 30;
```
- T-C3 → `cancelled` / `peer_busy` / `session_id IS NULL`
- T-C5 → `missed` / `unreachable`

## 6. 속도 측정 (⓪ 기준선 대비)

각 3회, Android A·C 기준. logcat epoch 와 화면 녹화로 잰다.

| 구간 | 시작 → 끝 |
|---|---|
| S1 메신저 첫 진입 | 하단 탭 터치 → 목록 첫 행 표시 |
| S2 채팅방 열기 | 행 탭 → 마지막 메시지 표시 |
| S3 목록 복귀 | 뒤로 → 목록 표시(스크롤 위치 유지 여부도 기록) |
| S4 메시지 전송 반영 | 전송 탭 → 내 말풍선 확정(시계 아이콘 사라짐) / 상대 기기 표시 |
| S5 통화 화면 진입 | 발신 탭 → 통화 화면 표시(`call_outgoing_tap` → `dialing_surface_shown`) |
| S6 통화 종료 후 채팅 복귀 | 종료 탭 → 채팅방 표시 |

결과는 p50 / 최대를 CSV(구간·기기·회차·ms)로 제출한다.

## 8. 결과 보고 형식 (Cursor → Owner)

- **첫 줄:** `[배포 구분] 웹만 — 확인한 Production SHA <sha>` (확인할 수 없었으면 NP)
- **표:** ID | 기기·버전 | PASS/FAIL/NP | 증거
- **FAIL:** 재현 단계 + logcat 10줄 + 스크린샷. 수정은 하지 않는다.
- **속도:** CSV 첨부
- **④⑤ 관찰 항목:** FAB·품질 경고·재통화·연결 끊김은 따로 표에 기록한다.
