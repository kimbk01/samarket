바뀐 점 (지금 운영 화면 대비)

1) 4칸 한 표 → 광고마다 카드(이름 줄 + 나오는 곳·시작 줄 + 기간/금액 2칸 표). 이름이 글자 중간에서 끊기지 않음(줄바꿈은 낱말 단위).
2) 각 광고에 신청하기 버튼 — 실제 결제 화면으로 이동. 위에 1·2·3 순서(고르기 → 결제 → 시작).
3) 머리에 내 포인트 / 내 매장 비즈 캐시 잔액 + 충전 버튼.
4) 탭은 스크롤해도 위에 고정, 「광고 문의하기」는 아래에 고정.
5) 금액 표기 ₱350.00 → ₱350(소수점 제거).
6) 팝업·당김 광고를 「운영팀과 상의해서 진행하는 광고 · 금액 문의」로 표시(지금은 앱 결제 경로가 없음).
금액은 11-26 운영 화면 값, 잔액·남은 자리는 예시 숫자.
