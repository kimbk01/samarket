# Cursor 실기기 검증 지시 — 커뮤니티 글쓰기 (main 56c86c40f)

## 0. 전제
- Production 웹 SHA 가 `56c86c40f` 이상인지 먼저 확인한다. (`https://samarket.vercel.app/api/philife/write-editor-mode` 가 200 이면 이번 배포 포함)
- 코드·DB·설정 변경 금지. 검증만 한다. 통화 검증 중인 기기는 통화 작업이 끝난 뒤 사용한다.
- 운영 DB 에 테스트 글·사진을 만드는 항목(★)은 Owner 승인 후에만 실행하고, 끝나면 테스트 글을 작성자 화면에서 삭제한다.
- 매 항목: 기기 · 시각(PHT) · 결과(PASS/FAIL) · 스크린샷 · FAIL 시 재현 절차.

## 1. 이미 확인됨 (Claude, Xiaomi 태블릿 24076RP19G, 일반 회원 계정, 글 작성 없음)
- 「최신순」에서 글쓰기 → 주제 선택 단계(8개, 이름만, 자동 선택 없음, 등록 비활성) PASS
- 주제 선택 → 작성 화면(주제 · 변경), 「변경」으로 주제 바꿔도 제목·본문 유지 PASS
- 하드웨어 뒤로가기: 주제 목록이면 목록만 닫힘 → 작성 화면에서 확인창 → 취소 시 유지 / 확인 시 시트 닫힘·피드 유지 PASS
- 주제 탭(여행정보)에서 글쓰기 → 해당 주제 미리 선택 PASS
- 일반 회원 계정에는 「새 편집기(검증용)」 토글이 보이지 않음 PASS

## 2. 기기별로 확인할 항목 (삼성 SM-M156S · 샤오미 24076RP19G · iPhone 14 Pro Max)

### A. 일반 회원 계정 (기존 편집기)
1. 위 1번 항목을 삼성·iPhone 에서 동일하게 확인 (iPhone 은 하드웨어 대신 왼쪽 가장자리 스와이프 뒤로가기)
2. 한글 입력: 제목·본문에 자연스럽게 한글 문장 입력 — 자모 분리·커서 튐 없음
3. 키보드: 본문 입력 중 커서·「등록하기」 버튼이 키보드에 가려지지 않음
4. ★ 사진 추가: 갤러리에서 3장 선택 → 썸네일 3개 표시, 업로드 중 「등록하기」 비활성·안내 문구 → 완료 후 활성
5. ★ 큰 사진(6MB 이상, iPhone 은 HEIC 포함) 1장 → 업로드 성공 또는 오류 안내(무반응이면 FAIL)
6. ★ 등록 → 게시글 **상세 화면**으로 이동 → 뒤로가기 → 피드 첫 화면에 새 글·썸네일 보임
7. ★ 수정: 상세 → 수정 → 주제 그대로 표시 → 본문만 고쳐 저장 → 상세로 이동, 주제·사진 유지
8. 「취소하기」 버튼: 내용 있으면 확인창, 빈 화면이면 바로 닫힘

### B. 관리자 테스트 계정 (새 편집기 — 일반 회원 비공개)
1. 글쓰기 → 주제 선택 → 「새 편집기(검증용)」 토글 보임 → 켬
2. 한글 입력: 조합 중 커서 이동·자모 분리 없음, 긴 글(여러 문단) 입력·스크롤
3. ★ 본문 중간에 커서 두고 「사진」 → 그 위치에 사진 표시, 사진 아래 줄에 이어서 입력
4. ★ 사진 「위로」「아래로」「삭제」, 삭제 후 실행 취소(키보드 Undo 가능 기기만)
5. ★ 업로드 중 계속 타이핑 → 완료 후 입력한 글자 유지
6. 「링크·동영상」 → YouTube 주소 입력 → 본문에 독립 줄로 들어감
7. ★ 등록 → 상세에서 글·사진 순서가 작성 화면과 동일, 피드 썸네일 = 본문 첫 사진
8. ★ 수정: 새 편집기로 다시 열림, 아무것도 안 고치고 저장해도 내용 동일
9. 하드웨어/스와이프 뒤로가기 확인창, 토글 끄면 기존 편집기로 내용 그대로 전환

## 3. 보고 형식
- 기기 × 항목 표(PASS/FAIL/미실행), FAIL 은 스크린샷·시각·재현 절차
- ★ 항목으로 만든 테스트 글 id 와 삭제 여부
- 코드 수정 없이 보고만 한다. FAIL 발견 시 즉시 중단하고 보고.
