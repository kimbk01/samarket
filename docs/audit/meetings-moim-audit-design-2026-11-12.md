## 1. 모임이란 무엇이고 왜 필요한가

### 1.1 당근이 밝힌 정의와 목적 (공식 출처)
- **정의**: "가까운 동네 이웃들이 함께, 자율적으로 만들어 가는 커뮤니티". 공통 관심사를 가진 이웃부터 동네 친구까지 **일정을 통해 연결**한다. (FAQ 3730 운영정책, 수정 2026-10-12)
- **지향**: "공통의 관심사나 목적을 가진 동네 이웃들이 **지속적으로** 함께 일정을 진행하는 커뮤니티". (FAQ 27663)
- **운영 철학**: 당근은 **최소한의 가이드라인**만 둔다. 회칙과 운영 방식은 **모임장·운영진의 자율**에 맡긴다. (FAQ 3730)

### 1.2 왜 필요한가 (근거 수치와 DIBAY 의미)

| 이유 | 당근 근거 | DIBAY 에서의 의미 |
|---|---|---|
| 일회성 거래를 **지속 관계**로 바꾼다 | 가입자의 절반이 2개 이상 모임에서 활동한다. 일정에 1회 참여한 사람의 58%가 다른 모임 일정에도 참여했다 (2024 1주년 발표) | 중고거래·동네생활 다음 단계인 **재방문 동기**. 리텐션을 공식 목적으로 밝힌 자료는 「확인 못 함」이고, 위 수치는 간접 지표다 |
| **오프라인 만남**이 플랫폼 안에서 일어난다 | 「같이해요」(반짝 모임)를 흡수해 정식 출시(2023-07-31). 2026 상반기 모임 MAU 1,000만 명 초과 | 필리핀 교민·현지 이웃의 운동·스터디·친목 수요를 외부 메신저(페이스북 그룹·바이버)에서 앱 안으로 가져온다 — **수요 규모는 NOT_PROVEN** |
| 플랫폼 **안전 관리**가 가능해진다 | 외부 앱 유도 금지, 개인정보 요구 금지, 신고·제재 단계 운영 | 모임이 외부 그룹으로 나가면 사기·포교·다단계를 DIBAY 가 볼 수 없다 |
| 지역 상권과 연결된다 (후순위) | 비즈프로필 연결(모임당 1개), 유료 일정 베타(2026-09, 수수료 3.3%) | 매장·D포인트와의 연결은 **이번 범위 밖**. Owner 결정 전에는 넣지 않는다 |

### 1.3 「채팅방」과 「모임」의 차이 (현재 DIBAY 문제의 핵심)

| 구분 | 채팅방(현재 DIBAY 오픈그룹) | 모임(당근) |
|---|---|---|
| 중심 | 메시지 흐름 | 멤버·일정·게시글 |
| 기록 | 대화가 흘러가 사라진다 | 공지·게시판·앨범·일정 후기가 남는다 |
| 만남 | 없음 | **일정(정모)**: 참여 신청 → 출석 → 후기 |
| 역할 | 방장·관리자 | 모임장·부모임장·운영진 + **권한 설정** |
| 플랫폼 관리 | 채팅 신고 | 모임 단위 경고·차단·모임장 제재 |

## 2. 당근 모임 상세 분석 (운영 방식)

출처는 각 항목에 FAQ 번호로 적었다(`https://www.daangn.com/wv/faqs/{번호}`). 【비공식】은 사용자 글이고, 「확인 못 함」은 공식 자료가 없는 항목이다.

### 2.1 개설
- **경로**: (+) → 주제(카테고리) → 이름·소개 → 가입 가능 연령대·정원 → 모집 동네 범위 → 가입 질문·모임장 승인 여부(선택). (2023 보도자료)
- **대표 사진**: 상단 배경 사진은 폐지되었다. 대신 앨범 사진 최대 6장을 고정한다. (14553)
- **반복 생성 제한**: 같은 취지·같은 동네의 모임을 반복 생성해 모집하는 것은 제한된다. (3730)
- **확인 못 함**: 1인당 개설 수 상한, 정원 최대치.

### 2.2 가입
- **바로 가입**: 닉네임과 간단한 소개만 입력하면 가입된다.
- **승인 가입**: 가입 질문에 답한 뒤 모임장이 승인한다.
- **가입 질문 금지 사항**: 실명·전화번호·신분 증빙 요구는 **정책 위반**이다. (3730, 27663)
- **가입 후**: 모임장봇이 환영 메시지를 보낸다. 가입 인사 게시판이 있다. (16005, 19994)
- **모임별 프로필**: 모임마다 닉네임·사진·소개를 따로 둔다. 재가입하면 다시 설정한다. (20832)
- **등급**: 준회원/정회원이 있고 등업은 신청 방식이다. 정회원 전용 게시판이 있다. (20832, 20731)
- **재가입**: 운영진에게 재가입 횟수가 표시되고 운영진 메모가 다시 연결된다. (21033)
- **재가입 차단**: 【비공식】 내보낼 때 「차단」을 체크하면 재가입할 수 없다.

- **모임장 위임**: 언제든 가능하다. 단 **경고 상태에서는 위임할 수 없고**, 고객센터에서 경고 해제를 받아야 한다. (3730)
- **모임장 장기 미접속**:
  - 30일 이상 미접속이면 멤버가 신청하고, 운영진 중에서 우선 검토한다.
  - 특별한 사유가 있으면 후보 2명 이상으로 7일간 멤버 투표를 한다.
  - 최근 7일 안에 접속 기록이 있으면 위임 불가. (34031)
- **확인 못 함**: 부모임장과 운영진의 권한 차이, 운영진 수 상한.

### 2.4 모임 안의 기능
- **홈 메뉴**: 홈 · 공지사항 · 모임 일정 · 챌린지. 섹션: 앨범 · 멤버 · 일정 · 게시글 (공개 모임 페이지에서 확인)
- **게시판**:
  - 여러 개를 운영한다. 자동 생성 게시판은 가입인사·일정 후기다.
  - 게시판별 공개 범위는 전체/정회원으로 나뉜다.
  - 글마다 「전체 공개」 또는 「모임에만 공개」를 고른다.
  - 투표가 있다. (20300, 22329, 31960)
- **일정(정모)** — 모임의 핵심:
  - 멤버도 만들 수 있다. 입력 항목: 활동·날짜·장소·설명·사진.
  - 반복 일정은 최대 6개까지.
  - 상태: 모집중/마감/종료. 인원 표시는 2/4명 형식.
  - 참여 방식은 **선착순** 또는 **신청 후 승인**이다.
  - 일정 호스트는 참여자를 내보낼 수 있고, 내보낸 사람은 그 일정에 재참여할 수 없다.
  - QR 출석 체크, 달력 보기, 일정 복사가 있다. (26978, 35970, 21676, 31498, 34733)
- **채팅**:
  - 전체 채팅방, **일정별 채팅방**(참여자만), 추가 생성 채팅방이 있다.
  - 멤버 간 1:1 채팅은 수락제다. (29884, 13841)
- **회비 규칙**:
  - 사용처와 반환 기준을 반드시 적는다.
  - 기준이 없으면 미참여 시 전액 반환이 원칙이다.
  - 반환하지 않으면 주최자가 제재를 받는다.
  - 당근은 분쟁의 당사자가 아니다. (3730)
- **성장 지표**:
  - 모임 레벨 Lv.0~5. Lv.4 이상은 동네 랭킹에 오르고, Lv.5 는 「우수 모임」이다. (16312)
  - 모임 통계(방문·새 글·새 멤버)가 있다. (33932)

### 2.5 플랫폼(당근) 관리
- **허용되지 않는 모임** (27663, 2026-10-27):
  - 영리·영업·홍보 목적
  - 물건 거래
  - 참가비를 받고 주류를 제공하는 모임
  - 로테이션 소개팅
  - 구인구직
  - 시술 모델 모집
  - 투자 강의·추천
  - 분양·브리딩
  - 사행성
  - **종교**(위장 포교는 엄격 조치, 종교 목적을 밝힌 모임도 현재 제한)
  - **정치**
  - **모임장의 이성 만남이 주 목적인 모임**
  - 불법·음란
- **금지 활동** (3730, 22079~22091):
  - 개인정보 요구, 동의 없는 단체 사진 게시
  - 노쇼
  - 다른 모임에서 자기 모임 홍보
  - 외부 메신저 유도
  - 활동 점수를 노린 반복 일정 생성
  - 개인 계좌로 참가비 받기
- **제재 단계** (22081 외):
  1. 콘텐츠·일정·모임 제한, 추천 제외
  2. **경고**(이 상태에서는 위임 불가)
  3. 경고가 쌓이면 **모임 차단**: 일정·글·채팅 전부 불가
  4. **모임장 본인 이용 제한**(기간 누적)
  - 현저히 부적절한 경우 즉시 차단할 수 있다.
- **추천 제외 ≠ 차단** (19462, 26672):
  - 외부 유도·영업성 표현이 있으면 추천에서만 뺀다.
  - 표현을 고치면 약 3시간 뒤 자동으로 복귀한다.
- **신고**:
  - 모임·게시글·일정 각각의 ⋮ 메뉴에서 신고한다.
  - 판단은 **앱 안 활동 기록**으로만 한다(오프라인 사건은 즉각 조치가 어렵다). (26507)
- **비활성 모임**:
  - 장기간 활동이 없으면 추천 제외·노출 제한만 한다(공식).
  - 자동 폐쇄는 「확인 못 함」이다.

### 5.1 구조 결정 (권고)

**모임 = 독립 도메인 `meetings`**
- 모임 홈(멤버·공지·게시판·일정·앨범)은 **커뮤니티 화면**이다.
- 채팅은 **기존 커뮤니티 메신저 그룹방을 모임에 종속**시켜 쓴다.
- 이렇게 하면 AGENTS.md 「채팅 3종」 경계(`community` 메신저)를 그대로 지킨다. 네 번째 채팅을 만들지 않는다.

**`meetings.post_id` 필수 연결을 끊는다**
- 모임은 게시글이 아니다.
- 모임 소개는 모임 홈에서 보여 준다.
- 동네생활 피드에는 「모임 카드」로만 노출한다.

**모임 채팅방의 성격**
- 모임 채팅방은 **「모임 멤버만 들어오는 방」**이다.
- 메신저의 오픈그룹 탐색·자유 가입 경로에서는 빼고, **입장 권한은 `meeting_members` 하나로만** 정한다. (S1 결함의 근본 해결)

**메신저 오픈그룹 「모임 찾기」의 정리**
- 지금 이것이 사실상 모임 역할을 한다.
- 모임이 생기면 이 진입은 모임 탐색으로 옮긴다.
- 기존 오픈그룹 8개의 처리는 Owner 결정이다(D1, D2).

### 5.6 유지·운영 규칙 (당근 공식 규칙을 기본으로 함)
- **모임장 탈퇴**: 멤버가 남아 있으면 위임을 먼저 해야 한다(당근은 【비공식】 근거 — D8 확정 필요).
- **위임 불가 조건**: 경고 상태에서는 위임할 수 없다(당근 3730).
- **미접속 위임**: 30일 이상 미접속이면 멤버 신청 → 어드민 처리. 최근 7일 안에 접속했으면 불가(당근 34031). 자동 위임 여부는 D9.
- **비활성 모임**: `last_activity_at` 기준으로 추천에서 제외한다. 자동 폐쇄는 하지 않는다(당근 공식은 노출 제한만 함).
- **모임 차단 시 범위**: 일정·글·채팅 전부 막고, 연결된 메신저 방을 읽기 전용으로 바꾼다(S3 해결).
- **삭제**: 소프트 삭제 + 메신저 방 보관 + 30일 뒤 정리(기간은 D10).
