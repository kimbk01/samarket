## 2. 고객지원 SSOT (구성)

- 내정보 홈 「고객지원」 카드 → **고객지원 화면 바로**(`/mypage/customer-center`). 분류 화면을 거치지 않는다(공지 글까지 4번 → 3번 누름).
- 고객지원 화면 = 「고객지원」 분류 화면 겸용: 제목 「고객지원」, **하단 탭 표시**(다른 분류 화면과 같음), ‹ = 앞 화면(기록 없으면 내정보 홈).
- 내용 = 문의하기 · 게시판 4개 · 신고/문의/포인트/충전 5줄(그대로) + 이용약관·개인정보처리방침·사업자 정보(분류 화면에서 옮김, 단일 정의 `supportPolicyRows()`).
- 옛 주소 `/mypage/section/support` → 서버에서 고객지원으로. 비로그인 「고객지원」 줄 이름 통일.
- 문의 CTA = 「문의하기」 하나(기존 문의 창). 화면별 고객센터 FAB 는 그 화면 맥락 문의라 변경 없음.
