# 서버 콜백 가입 뒤 「로그인 사용자 값 없음」 — 원인·영향 전수·수정 설계 (2026-11-27 · v2)

원인 감사: `docs/audit/signup-mypage-skeleton-root-cause-2026-11-27.md`. 이 문서는 v1(내정보만 본 설계)을 대체한다.
[배포 구분] 웹만 — 네이티브·DB·통화 서버 코드 변경 없음. **Owner 승인 전 커밋·PR·배포 없음.**

## 0. 내 잘못 (먼저)
- v1 설계는 내정보 카드만 보고 「다른 화면은 미조사」「로그인 필요 창 경로 확인 못 함」을 남긴 채 구현에 들어갔다. 이번 v2 에서 전부 확인했다.
- 「설계대로 구현」 지시 뒤 작업 폴더에서 구현·로컬 검사를 시작했다(커밋·PR·배포 없음). 그 검사에서 내가 넣은 한국어 JSX 주석이 언어 검사(jsx-text-korean)를 1건 늘린 것을 찾아 일반 주석으로 옮겼다.

## 1. 결함 (FAIL)
같은 앱 실행에서 **로그아웃 표시가 켜진 뒤**(§2-1) **서버 콜백 로그인**(§2-3 표)으로 들어와 **가입 단계 화면**(`/auth/onboarding/*`)을 거치면,
그 실행이 끝날 때까지 앱 안 「로그인 사용자 값」(`getCurrentUser()`)이 비어 있다. 서버 세션·하단 탭 사진(앱 시작 프로필)·회원 판정은 「로그인」이라 화면은 회원 화면인데, 이 값을 쓰는 기능이 비회원처럼 동작하거나 멈춘다(§3 — 내정보 카드는 그중 하나). 앱 재시작(세션 저장소 비움)으로만 풀린다.
실측: Owner iPhone · 운영 `2203d00` · 08:57 PHT · 재가입 계정 `0d08ec52` · 재시작하면 정상(Owner 확인).

## 2. 원인 — 전수 확인
### 2-1. 표시를 켜는 곳 (3)
`wipeClientSessionState` 기본값: 사유가 `user_logout`·`account_switched` 이면 표시 켬 (`lib/auth/client-session-wipe.ts:339-341`).

| 세션 끊김 강제 로그아웃 | `dibay-session-manager.ts:206·239` |

(개발용 `reset-auth-state.ts:10` — 운영 노출 없음)

### 2-2. 표시가 막는 것 (1)
`setSupabaseProfileCache(값)` 만 무시 (`supabase-profile-cache.ts:26`). 이 표시를 읽는 다른 곳 없음(전수 grep).
값을 넣는 곳 9개 중 처음 로그인 때 쓰이는 앱 시작(`run-app-boot.ts:199·487`)·`SupabaseAuthSync.tsx:86`·세션 준비(`auth-session-immediate.client.ts:49`)는 넣은 뒤 「로그인 변경」 신호를 보낸다 — 표시 때문에 값은 안 들어갔는데 신호만 나가 듣는 화면들이 빈 값을 다시 읽는다.

### 2-3. 표시를 지우는 곳 (2) 과 로그인 경로
| 지우는 곳 | 붙는 범위 |
|---|---|
| 앱 안 로그인 완료 `runCommonAuthClientCompletion` 79행 (`finishClientAuthLogin` 경유) | 앱 안 SDK·아이디 로그인만 |
| `PostLogoutBfcacheGuard` — 인증된 부팅 준비 신호 때 | **`(main)` 화면 묶음에만** (`MainAppProviderTree.tsx:211`) |

| 로그인 (경로 `oauth-native-routing.ts:62-131`) | iOS | Android | 웹 |
|---|---|---|---|
| Google | 서버 콜백 | 앱 안 SDK | 서버 콜백 |
| Apple | 앱 안 SDK | 서버 콜백 | 서버 콜백 |
| 카카오 | 서버 콜백 | 앱 안 SDK | 서버 콜백 |
| 아이디 | 앱 안 | 앱 안 | 앱 안 |

서버 콜백은 앱 안 완료 처리를 거치지 않는다. 가입이 끝난 회원은 콜백이 메인 화면 문서로 보내 `PostLogoutBfcacheGuard` 가 부팅 준비 때 지운다(정상).
가입 단계가 남은 회원은 콜백이 `/auth/onboarding/terms`(루트 레이아웃만)로 보내 부팅이 거기서 끝난다 → 지우는 부품 없음 → 가입 완료 뒤 홈은 앱 안 이동이라 부팅 준비 신호가 다시 없음 → **표시가 실행 끝까지 남는다.**

「로그인 필요」 창에서 이어지는 로그인(`finishClientAuthLogin` pendingToken 분기 130-137행)은 79행을 거치지 않지만, 메인 화면에서 열리고 `ensureAppBoot` 로 익명→인증 부팅 준비 신호가 나므로 메인의 부품이 지운다 — 이번 결함 경로 아님(코드 확인 · 실측 없음, §6 V7 로 실측).

### 2-4. 언제부터 — 최근 변경 아님
