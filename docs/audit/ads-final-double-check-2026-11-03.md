- **H-1** 거래 종료 실패 (§2-1).
- **H-2** 피드 반려가 허브(API)와 도메인에서 다른 경로로 저장된다. 허브 쪽은 트랜잭션이 아니다. 버튼으로는 갈 수 없고 API 로만 열려 있다.
- **H-3** 커뮤니티 조치: 허브는 재개 사유가 없고, 감사 기록에 변경 전 값이 없다.
- **H-4** 허브 목록 행 버튼이 권한을 보지 않는다. 그래서 사유를 쓴 뒤에 403 이 난다. PTR·피드 상품·회원 신청 상세·프로모션 배너·배달 만들기 화면도 버튼 권한 검사가 없다.
- **H-5** 막힌 링크
  - 이력의 배달 「상세」가 `/admin/stores/delivery-ads/{id}` 로 가서 **404** 다(✓ 경로 없음 확인).
  - 피드 「상세」가 같은 목록으로 돌아온다.
  - 상위노출 「상세」가 목록 자체다.
  - `?slot` 이 이동하면서 사라진다.
  - 두 번 이동하는 링크가 있다.
- **H-6** 공통 허브에 없는 것: 인트로·PTR·마이페이지 배너·이벤트. 도메인 메뉴에 없는 것: 사장님 팝업·매장 홍보 신청(배달), 회원 배너 신청(거래·커뮤니티), 커뮤니티 가격. 허브에는 `?domain=` 거름 조건이 없다.
- **H-7** 문구
  - 옛 메뉴 이름이 남아 있다: 「프로모션 / 이벤트」 「광고 / 노출」.
  - 같은 것을 다르게 부른다: 상위노출 / 상위 노출 / 홍보 / 제재, 매장홍보 / 매장 홍보.
  - 영어·코드가 그대로 나온다: Popup, Boost, Hero, writer, surface, 코드값.
  - 빈 화면에 등록 버튼이 없다.
  - 「배달 홈 상단 배너」 카드가 실제로는 배달 배너 4종 만들기 화면을 연다.
- **H-8** 쓰지 않는 컴포넌트 11개 (보고만).
