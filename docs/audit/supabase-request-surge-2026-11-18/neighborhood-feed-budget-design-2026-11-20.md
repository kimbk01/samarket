| 순서 | 바꾸는 것 | 방식 | 요청당 |
|---|---|---|---|
| 1 | 주제 목록 | 인스턴스 메모리(45초) 앞에 **인스턴스 공유 캐시**(`unstable_cache` + 태그, #497 상단 캐시와 같은 방식). 관리자 주제 수정 경로에서 태그 무효화 | 0.69 → 약 0 |

| | **합계** | | **6.51 → 약 4.2** (예산 6.4 → 낮춤 대상) |

- 바뀌는 동작: 관리자가 주제를 바꾼 직후 반영 — 태그 무효화로 즉시(지금 45초보다 빠르거나 같음).
- 위험: 공유 캐시 읽기는 Vercel 데이터 캐시 요청으로 남는다(Supabase 아님). 동네 id 를 잘못 캐시하면 피드가 비는데, 결과 있는 경우만 캐시하므로 「없음 → 생성 후에도 없음」 문제는 없다.
