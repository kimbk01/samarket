## 2. 레거시 구조와 차이

| | 레거시(배민·카카오 등) | DIBAY |
|---|---|---|
| 할 일 확인 | DB 안 예약(또는 큐)이 「때가 된 행」만 처리. 할 일이 없으면 외부 호출 0 | 작업 하나가 하위 단계마다 따로 조회 → 할 일이 없어도 단계 수만큼 호출 |
| 한 번의 실행 | 「때가 된 것 전부」를 DB 함수 1번으로 | 단계별 RPC·표 조회 4~11번 |
