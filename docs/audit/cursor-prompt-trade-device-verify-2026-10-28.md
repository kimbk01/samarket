# Cursor 지시 — 거래 승인 범위 실기기 검증 (2026-10-28 PHT)

## 0. 목적과 규칙

- 거래 재감사·설계안(`docs/audit/trade-reaudit-and-design-2026-10-28.md`) 승인 범위가 Production 에 반영됐다. 이 문서의 시나리오를 **기기 화면에서 직접 조작**해 하나씩 확인하고, 끝에 한 번 보고한다.
- 하지 않는 것:
  - 코드·설정·DB 를 바꾸지 않는다. 커밋·푸시하지 않는다. 앱을 삭제하지 않는다.
  - 주소창에 API 를 넣거나 `curl` 결과만 보고 PASS 를 주지 않는다. **화면에서 누르고 보이는 것**이 기준이다. 예외는 §1 배포 확인과 §4 DB 대조뿐이다.
  - 테스트 DB(`dibay-test`·`dibay-reset-qa`)는 쓰지 않는다. 운영 DB(`ckdosyydvgzqwpbwuhon`)는 **SELECT 만** 쓴다.
  - 새 거래 글을 등록하지 않는다(사진 0장 막힘 확인은 등록 버튼까지만 누른다).
  - 아래 지정 글 말고 다른 글을 판매완료로 바꾸지 않는다. **판매완료는 되돌릴 수 없다.**
- 확인하지 못한 것은 NOT_PROVEN 으로 적는다. 추측으로 PASS 를 주지 않는다.
- 실패가 나와도 고치지 않는다. 증거를 남기고 다음 시나리오로 넘어간다.

## 1. 시작 전 확인 (모두 맞아야 시작)

1. **배포 확인.** 아래 두 줄의 응답에 `307` 과 `location:` 값이 보여야 새 배포다.
   ```
   curl -sI https://samarket.vercel.app/mypage/trade/reviews | grep -iE "^HTTP|^location"
   curl -sI "https://samarket.vercel.app/market/location" | grep -iE "^HTTP|^location"
   ```
   - 기대: 첫 줄은 `location: /mypage/products`, 둘째 줄은 `location: /market?locSheet=1`.
   - 다르면 **멈추고** 원문을 보고한다(배포 전 상태).
2. **기기와 설치 버전.** `adb devices -l` 로 기기를 확인하고, 각 기기의 앱 버전을 적는다.
   ```
   adb -s <기기> shell dumpsys package com.dibay.app | grep -E "versionName|versionCode"
   ```
   - Samsung `RFCY40PY2CA`(384×832, 로그인 계정 `9259ab7d-ae5f-4d4a-819a-8d5bd568ecf8`)
   - Xiaomi 태블릿 `8b37179f7d94`(800×1340). adb 탭·스크린샷만 가능하다. 로그인 계정 id 를 화면에서 확인해 적는다.
   - iPhone: 연결되어 있으면 Xcode Devices 에서 버전을 적는다. 연결이 안 되면 iPhone 칸은 전부 NOT_PROVEN 이다.
3. **앱 재시작.** 웹 변경이라 앱을 완전히 종료한 뒤 다시 연다(재설치 불필요).
4. **Samsung 화면 읽기(선택).** WebView 디버그 포트를 연결하면 DOM·콘솔 오류를 함께 볼 수 있다.
   ```
   SOCK=$(adb -s RFCY40PY2CA shell cat /proc/net/unix | grep -o "webview_devtools_remote_[0-9]*" | head -1); adb -s RFCY40PY2CA forward tcp:9224 localabstract:$SOCK
   ```
5. **증거 저장 위치.** 스크린샷은 `adb -s <기기> exec-out screencap -p > <파일>` 로 찍는다. 저장 폴더는 `docs/audit/evidence/trade-2026-10-28/` 이고, 파일 이름은 `S<번호>-<기기>-<pass|fail>.png` 로 한다.

## 4. DB 대조 (SELECT 만)

```sql
-- S6: 공개 거래 글 수
select count(*) from posts
 where trade_category_id is not null and coalesce(is_deleted,false)=false and status<>'hidden'
   and coalesce(moderation_state,'visible')='visible' and coalesce(owner_state,'none')='none';

-- S11-b: Samsung 계정 성과(조회수·찜·신고)
with mine as (
  select id, view_count, favorite_count from posts
   where user_id='9259ab7d-ae5f-4d4a-819a-8d5bd568ecf8' and trade_category_id is not null
     and owner_state <> 'owner_deleted')
select (select coalesce(sum(view_count),0) from mine) views,
       (select coalesce(sum(favorite_count),0) from mine) favorites,
       (select count(*) from reports r where r.target_type='product' and r.target_id in (select id::text from mine)) reports;

-- S17: Samsung 계정이 신고한 거래 글
select target_id from reports where reporter_id='9259ab7d-ae5f-4d4a-819a-8d5bd568ecf8' and target_type='product';

-- S2-b 확인: 지정 글 상태
select id, status, seller_listing_state from posts where id='20331da7-4328-46b8-be6d-25c9ea7416a5';
```
