## 0. 작업자 잘못 (먼저 보고)
1. 단계별 보고에서 「구현 완료」라고 했지만, 아래 §1 의 결함 A1~A8 은 **제가 만든 구현 결함**입니다. 특히 A1(「수락」 버튼이 수락이 아니라 새 요청을 보냄)은 계획 §5-5·S6 의 핵심 흐름이 동작하지 않는 상태입니다.
2. 계획 §13 의 「관리」 시트 2줄(숨긴 추천·연락처 동기화)과 넓은 화면(768px 이상) 오른쪽 칸 표시는 구현하지 않았는데 보고에서 빠뜨렸습니다.
3. 2단계 보고에서 시안 대조(UI·CTA SSOT)를 하지 않고 「반영」이라고 썼습니다 (§3).

## 3. 시안·UI·UX·CTA SSOT 어긋남 (감사만 — 고칠 때 화면별 재확인)
1. 동의: 시안은 전체 화면 → 구현은 시트 · 동의 후 연락처 화면으로 안 넘어감 · 실패 안내 없음.
2. 차단·추천 숨김: 확인 대화상자 없음 (시안·메신저 기존 차단은 확인 후 실행).
3. 설정: 직접 만든 토글·기본 select → 메신저 `SwitchRow`/`NavRow` SSOT 미사용.
4. 회원 행: 사진과 이름 사이 간격 없음 · 오른쪽 여백 과다 · 「요청됨」 흐림(opacity) 처리 (SSOT 금지).
5. 불러오는 중·오류·다시 시도 상태 없음 · 「모두 보기」 높이 32px (최소 터치 높이 미달).
6. 결과 안내(스낵바) 없음 · 철회 문구 개수 없음 · 다른 기기 삭제 대화상자가 「이 기기」 설명을 씀.
7. 뒤로 버튼 이름 「취소」 · 이전 화면 없을 때 갈 곳 없음 · 머리글이 메신저 `DetailHeader` 와 다름.
8. 초대 행: 사진 자리·가린 번호 없음 · 출처 줄에 기기 이름 없음.
