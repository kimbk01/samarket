# 배달 업종 화면 표시 방식 — 어드민 지정 설계안 (2026-10-29 PHT)

- 범위: 조사·설계만. 코드·DB 변경, 커밋, 배포 없음.
- **Owner 지시**
  - 1차 업종마다 고객 화면을 어떻게 보일지 **어드민이 정확히 지정**하고, 앱이 그대로 동작해야 한다.
  - 수수료는 바꾸지 않는다. 3차 추가도 하지 않는다.

---

## 1. 표시 방식 3가지 (1차 업종마다 어드민이 하나 선택)

| 방식 | 고객이 1차를 누르면 | 예 |
|---|---|---|
| **A. 배민형** | 위쪽에 2차 탭 줄(전체 · 한식 · 중식 · 분식 …), 아래 매장 목록. 탭을 누르면 같은 화면에서 목록만 바뀜 | 식당 |
| **B. 전체 매장** | 탭 없이 그 1차의 매장 전체를 한 목록으로 | 공구류·학원 |
| **C. 1차 → 2차 → 매장** | 먼저 2차 목록(아이콘)이 나오고, 2차를 누르면 그 2차의 매장 목록 | 마트·서비스 |

- 기본값: 지정하지 않은 1차는 **A** (지금 화면과 가장 가까움).
- 2차가 1개뿐이거나 노출 중인 2차가 없으면 A·C도 B처럼 보인다.

## 2. 어드민

- 위치: `/admin/delivery-screens` → 「업종 목록 화면」 탭 (기존). 1차를 고르면 「표시 방식: A / B / C」 선택.
- 2차 순서·켜기/끄기·이미지·이름: 기존 「업종 분류」 탭 그대로 사용.
- 저장 위치: 기존 업종 정책(`store_browse_scope_policy`)의 1차 행 설정값(`productConfig`)에 `displayMode` 추가.
  - 새 테이블·새 컬럼이 없으므로 **DB 변경이 없다**.
- 저장하면 고객 앱에 반영된다. 기존 업종 캐시 갱신 경로를 쓰므로 앱을 다시 열거나 당겨서 새로고침하면 된다.

## 3. 앱 화면 (모두 웹 수정, 앱 재빌드 없음)

| 방식 | 화면 구성 |
|---|---|
| A | 상단바 「← 식당 ⌄」 → 2차 텍스트 탭 + 밑줄 → 정렬 칩 → 매장 목록. 배민 업종 설계안 §5·§7 그대로 |
| B | 상단바 「← 공구류 ⌄」 → 정렬 칩 → 매장 목록 (탭 줄 없음) |
| C | 상단바 「← 마트 ⌄」 → 2차 아이콘 목록(한 줄 4개) → 누르면 「← 한인마트」 매장 목록 화면 |

- URL: A는 `?sub=` 를 탭에 사용한다. B는 `sub` 없이 쓴다. C는 2차 목록 화면에서 2차를 고르면 `?sub=` 로 매장 목록 화면이 열린다. 지금 있는 링크는 그대로 동작한다.
- 홈 아이콘(1차)을 누르면 그 1차에 지정된 방식의 화면으로 바로 간다.

## 4. 수정 대상

| 구분 | 파일 |
|---|---|
| 어드민 | `components/admin/stores/delivery-screens/DeliveryScreensBrowseTab.tsx`, 업종 정책 저장 API (`productConfig.displayMode`) |
| 정책 | `lib/stores/product/stores-browse-scope-policy-catalog.ts` (displayMode 읽기·기본값 A) |
| 앱 | `StoresBrowseHeaderChrome.tsx`, `StoresBrowseHeaderPrimaryTabs.tsx`, `StoresBrowseHeaderSubTopicChips.tsx`, `StoresBrowsePrimaryView.tsx`, 홈 1차 아이콘 이동 (`StoresHomeCategoryStickyBelow.tsx`) |
| 테스트 | displayMode별 화면 분기·기본값 vitest |

- 배포 구분: **웹만**. DB 변경 없음, 네이티브 재빌드 없음.
- 진행 시점: 배민형 업종 화면 작업과 같은 배포로 묶는다.

## 5. 검증 (운영 앱, Production SHA 기록)

1. 식당 = A → 탭 줄, 탭 누르면 목록만 바뀜
2. 공구류 = B → 탭 없이 전체 매장
3. 마트 = C → 2차 목록 → 한인마트 누르면 한인마트 매장
4. 어드민에서 식당을 B로 바꿈 → 앱 새로고침 → 탭 없이 전체 매장
5. 지정 안 한 1차 → A
6. 뒤로가기: C의 매장 목록 → 2차 목록 → 홈
