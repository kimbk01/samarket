## 3. 두 창이 서로 다른 것

| 항목 | 거래 | 커뮤니티 |
|---|---|---|
| 잔액 위치 | 맨 위 큰 글씨 + 충전 | 맨 아래(스크롤) |
| 상품 줄 | 제목 + 위치 1줄 + 가격 + 부족분 | 제목 + 설명 4줄 + 가격 |
| 주 버튼 | 「500P로 시작 / 연장」 | 「포인트로 상위노출하기 / 연장하기」(금액 없음) |
| 부족한 상품 | 못 고름 · 줄에 「N P 부족」 | 고를 수 있음 · 버튼만 꺼짐 |
| 충전 이동 | 충전 신청 + 부족분 | 포인트 메인 |
| 결제 뒤 잔액 | 안 바뀜(결함 ②) | 바뀜 |
| 고객 문의 | 있음 | 없음 |

## 4. 결함 목록 (화면으로 본 것만)

1. 거래 「고객 문의」 관련 항목이 uuid(`256bd425…`)로 보임.
2. 거래 창 결제·연장 뒤 「내 포인트」가 결제 전 값으로 남음(2번 재현).
3. 거래 창 운영자 정지 줄에 「운영자가 … 멈췄습니다」와 「운영자가 잠시 멈춤」이 함께 나옴.
4. ~~거래 창 운영자 정지 때 주 버튼이 「포인트 충전」~~ — **철회(2026-11-08 설계 때 정정)**: 배너 상품이 남아 있고 포인트가 모자라 시안 v3 규칙대로다. 작업자 판단 잘못.
5. 커뮤니티 창 상품마다 4줄 설명 + 「적용 위치」 상자가 같은 말을 반복.
6. 커뮤니티 창 주 버튼에 금액이 없음.
7. 커뮤니티 창 잔액·「포인트가 부족합니다」가 스크롤 아래에 있어 처음 화면에 안 보임.
8. 커뮤니티 「포인트 충전」이 충전 신청(부족분) 대신 포인트 메인으로 감.
9. 커뮤니티 창은 잔액보다 비싼 상품도 고를 수 있고 줄에 부족분 표시가 없음.
