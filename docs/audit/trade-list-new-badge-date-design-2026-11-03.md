## 4. 설계안 (시안 v5)

### D1 상단
- 「새 매물 N개」: 높이 0으로 띄운다(목록이 밀리지 않음). CUT H 동작은 유지. N은 보이는 글 중 가장 최근 글보다 늦게 작성된 글만 센다(L1·L2).
- 상단 이벤트 배너: 배너가 없으면 감싸는 칸을 그리지 않는다(L12). 배너가 있으면 지금 자리.

### D2 카드 — 정형 (모든 카드 같은 자리)
| 자리 | 내용 |
|---|---|
| 사진 왼쪽 위 | **상태 칩 1개** — 판매자 광고면 「광고」(그린 바탕·흰 글자), 작성 24시간 안이면 「NEW」(흰 바탕·#362415 글자), 둘 다 아니면 비움. 페이스북 「방금 등록된 품목」 칩 자리 |
| 사진 오른쪽 위 | ♡ (그대로) |
| 사진 왼쪽 아래 | 주제 배지 (지금 자리·모양 그대로, 어떤 카드도 안 움직임) |
| 사진 가운데 | 예약중·판매완료 |
| 1줄 22px | 가격 16px/700 왼쪽 (안 잘림) · 작성일 12px/400 #604C4C 오른쪽 (항상) |
| 2줄 20px | 제목 14px/500 · 1줄 고정 · 「…」 |
| 3줄 18px | 지도 아이콘(현재 lucide `MapPin` 12px) + 지역 12px · 관심 N |
- 글꼴 Pretendard Variable, 색은 앱 토큰. 부동산·일자리 금액도 1줄.
- 시간 문구: 당근과 같은 경계(초·분·시간·일<30·개월<12·년), 날짜로 바꾸지 않음. 거래 전용 함수 1곳을 목록과 거래 상세가 함께 쓴다(L4·L5).

### D3 판매자 광고(더 알리기)
- 카드 둘레 DIBAY 그린 3px **바깥선**(`outline`, offset 2px) → 카드 크기·칸 자리 변화 0. 2칸 간격 10px 안에 들어간다.
- 사진 왼쪽 위 「광고」 칩. 텍스트 줄(관심 N 등)은 건드리지 않는다(L13·v4 겹침 정정).
- 판정은 기존 `postHasTradePromotionOverlay`, 고정 ≤3·순서는 CUT F 그대로.

### D4 피드 광고(광고주 배너)
- 격자에서 **2칸 전체 한 줄**(`grid-column: 1 / -1`)로 쓴다. 페이스북처럼 줄 단위로 들어가 열이 어긋나지 않는다(L11).
- 머리: 광고주 동그라미 32px · 이름 14px/700 · 「광고」 12px #604C4C → 3:1 배너 → 문구 1줄 14px/500.
  - 구현 메모(2026-11-03): 광고주 이름 = 캠페인 「이름」(어드민 입력, 이미 문구 대체값으로 고객에게 보이던 값). 「···」(광고 숨기기·신고)는 처리 기능이 없어 동작 없는 버튼이 되므로 넣지 않았다 — 별도 승인 과제.
- 넣는 자리: 짝수 번째 글 뒤에만 넣는다. 간격 정책(4~6)을 2열에서는 4 또는 6으로 맞춘다 — `feed-ad-slot-policy` 에 열 수 인자 추가. 커뮤니티(1열)는 그대로.

### D5 ⋮ → 길게 누름
- 카드에서 ⋮를 없앤다. 카드를 길게 누르면 메뉴 시트가 열린다(페이스북과 같음). iOS 길게 누름 미리보기·복사 메뉴는 막는다(`-webkit-touch-callout:none`, `contextmenu` 막기).
- 메뉴 정리: 「관심 있음」 삭제(L8) · 「게시글 노출 기준」 삭제(L9) · 「관심 없음」과 「이 글 숨기기」를 「이 글 숨기기」 하나로(L10) · 「신고하기」 유지 · 내 글이면 「수정」「삭제」.
- 숨김 저장(다시 열어도 숨김 유지)은 새 저장소가 필요해 이번 범위 밖 — 보고만 한다.

### D6 예약중 (Owner 결정)
판매완료와 같은 자리·모양(사진 가운데 검정 75%). 누를 수 있다.
