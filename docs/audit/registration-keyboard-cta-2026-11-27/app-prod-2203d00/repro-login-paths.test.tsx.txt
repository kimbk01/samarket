// @vitest-environment jsdom
/** 임시 재현(커밋 안 함) — 로그인 경로 3종에서 로그아웃 표시·로그인 사용자 값·내정보 조회 */
import { act } from "react";
import { createRoot } from "react-dom/client";
import { beforeEach, describe, expect, it, vi } from "vitest";

vi.mock("@/lib/supabase/client", () => ({ getSupabaseClient: () => null }));
const UID = "0d08ec52-c77e-45b8-96fd-f8a778633e6e";
const GUARD = "samarket:post_logout_guard";
const fetchSpy = vi.fn(async (..._a: unknown[]) => new Response("{}", { status: 500 }));

async function mountMyModel() {
  const { useMypageHomeModel } = await import("@/hooks/use-mypage-home-model");
  const seen: Array<{ p: unknown; e: boolean; r: boolean }> = [];
  function Probe() {
    const m = useMypageHomeModel(true);
    seen.push({ p: m.projection, e: m.loadFailed, r: m.needsRelogin });
    return null;
  }
  const h = document.createElement("div");
  document.body.appendChild(h);
  fetchSpy.mockClear();
  await act(async () => createRoot(h).render(<Probe />));
  await act(async () => new Promise((r) => setTimeout(r, 300)));
  const urls = fetchSpy.mock.calls.map((c) => String(c[0]));
  return { last: seen[seen.length - 1]!, profileOrAddr: urls.filter((u) => /api\/me\/(profile|address-defaults)/.test(u)) };
}

async function mountGuardComponent() {
  const { PostLogoutBfcacheGuard } = await import("@/components/auth/PostLogoutBfcacheGuard");
  const h = document.createElement("div");
  document.body.appendChild(h);
  await act(async () => createRoot(h).render(<PostLogoutBfcacheGuard />));
}

describe("login path matrix after logout", () => {
  beforeEach(() => {
    vi.resetModules();
    (globalThis as unknown as { IS_REACT_ACT_ENVIRONMENT: boolean }).IS_REACT_ACT_ENVIRONMENT = true;
    globalThis.fetch = fetchSpy as unknown as typeof fetch;
    sessionStorage.clear();
    sessionStorage.setItem(GUARD, "1"); // 로그아웃
  });

  it("A 웹 로그인(서버 콜백) → 가입 단계 화면에서 부팅 → 앱 안 이동 → MY", async () => {
    const cache = await import("@/lib/auth/supabase-profile-cache");
    const boot = await import("@/lib/app-boot/app-boot-store");
    const { getCurrentUser } = await import("@/lib/auth/get-current-user");
    cache.setSupabaseProfileCache({ id: UID } as never); // 부팅이 넣으려 함
    boot.setAppBootProfile({ id: UID } as never); // 부팅 준비(가입 화면 — 표시 지우는 부품 없음)
    await mountGuardComponent(); // (main) 이동 뒤 붙음
    const r = await mountMyModel();
    console.log("A", sessionStorage.getItem(GUARD), getCurrentUser()?.id ?? null, JSON.stringify(r));
    expect(getCurrentUser()).toBeNull();
    expect(r.last.p).toBeNull();
    expect(r.profileOrAddr).toEqual([]);
  });

  it("B 앱 안 로그인 완료(runCommonAuthClientCompletion 79행과 같은 호출) → 부팅 → MY", async () => {
    const wipe = await import("@/lib/auth/client-session-wipe");
    const cache = await import("@/lib/auth/supabase-profile-cache");
    const boot = await import("@/lib/app-boot/app-boot-store");
    const { getCurrentUser } = await import("@/lib/auth/get-current-user");
    wipe.clearPostLogoutBfcacheGuard();
    cache.setSupabaseProfileCache({ id: UID } as never);
    boot.setAppBootProfile({ id: UID } as never);
    const r = await mountMyModel();
    console.log("B", sessionStorage.getItem(GUARD), getCurrentUser()?.id ?? null, JSON.stringify({ p: !!r.last.p, profileOrAddr: r.profileOrAddr }));
    expect(getCurrentUser()?.id).toBe(UID);
    expect(r.last.p).not.toBeNull();
  });

  it("C 웹 로그인(서버 콜백) → 기존 회원은 메인 화면 문서로 바로 → 부팅 준비 때 표시 삭제", async () => {
    const cache = await import("@/lib/auth/supabase-profile-cache");
    const boot = await import("@/lib/app-boot/app-boot-store");
    const { getCurrentUser } = await import("@/lib/auth/get-current-user");
    await mountGuardComponent(); // 메인 화면 문서 — 부품이 먼저 붙음
    cache.setSupabaseProfileCache({ id: UID } as never); // 부팅의 첫 시도는 막힘
    await act(async () => boot.setAppBootProfile({ id: UID } as never)); // 준비 신호 → 표시 삭제
    const guardAfter = sessionStorage.getItem(GUARD);
    cache.setSupabaseProfileCache({ id: UID } as never); // SupabaseAuthSync 준비 신호 처리(getUser 뒤)와 같은 재시도
    console.log("C", guardAfter, getCurrentUser()?.id ?? null);
    expect(guardAfter).toBeNull();
    expect(getCurrentUser()?.id).toBe(UID);
  });
});
