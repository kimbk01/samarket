# Android 알림 아이콘·색이 기기마다 다르게 보임 — 원인·수정안 (2026-10-29 · 커밋 안 함 · Owner 승인 대기)

## 1. 사실
- 알림 카드 모양(둥근 카드, 글자 배치, 묶음, 펼치기 버튼, 시간 표시)은 **OS 가 그린다**. 앱은 내용만 넘긴다(작은 아이콘, 색, 제목, 본문, 큰 이미지, 버튼).
  - 아이폰은 iOS, 삼성은 One UI, 샤오미는 HyperOS 가 그린다.
  - 그래서 세 기기를 픽셀 단위로 똑같이 만드는 방법은 없다(OS 제약).
- 아이폰: 알림 아이콘을 앱 아이콘으로 iOS 가 자동으로 표시한다. 앱 쪽 설정이 없다.
- Android: 앱이 `setSmallIcon` 으로 지정한 **작은 아이콘을 OS 가 단색(흰색 실루엣)으로 바꿔** 표시한다.
  - DIBAY 는 모든 알림에 **컬러 앱 아이콘 `R.mipmap.ic_launcher`** 를 지정한다. 알림 전용 단색 아이콘과 `setColor` 가 없다.
  - 지정한 곳: `DibayFirebaseMessagingService`, `DibayAppIconDeliveryAdapter`, 통화 알림 6곳.
  - 컬러 아이콘은 불투명한 사각형이라, 단색으로 바꾸면 **빈 사각형·원 모양**이 된다(샤오미 알림창 캡처 `claude-r3/k15-shade.png` 의 DIBAY 아이콘).
  - 제조사마다 이 경우를 처리하는 방식이 달라 삼성·샤오미 표시가 서로 다르다.

## 2. 맞출 수 있는 것 (수정안)
- Android 알림 전용 단색 아이콘 `ic_stat_dibay`(DIBAY 마크, 흰색 + 투명 배경 · 벡터)를 추가한다.
- 일반 알림 경로의 `setSmallIcon` 을 이 아이콘으로 바꾸고 `setColor(#0B421A)`(브랜드 그린)를 지정한다.
- 매니페스트에 FCM 기본 아이콘·색 메타데이터를 추가한다.
- 결과
  - 삼성·샤오미 모두 같은 DIBAY 마크와 같은 강조색으로 보인다.
  - 아이폰은 앱 아이콘 그대로다.
  - 제목·본문·이동 동작은 세 기기에서 이미 같다(서버가 같은 내용을 보낸다).
- **통화 알림 6곳은 바꾸지 않는다.** 통화 규정상 별도 계획·승인·통화 행렬 실기가 필요하다. 이번 범위에서 빼면 통화 알림 아이콘만 기존 모양으로 남는다.

## 3. 필요한 것
- 네이티브 변경이다. Android versionCode 16 재빌드와 S·X 재설치가 필요하다. iOS 는 무변경이다.
- 아이콘 원본: DIBAY 마크 단색 SVG. 기존 브랜드 자산에서 추출할 수 있는지 구현 전에 확인한다. 없으면 Owner 제공이 필요하다.
- 검증
  - S·X 메시지·주문·공지 알림을 알림창에 띄워 캡처 대조
  - 통화 C5 1회 회귀 확인(같은 빌드라서)
