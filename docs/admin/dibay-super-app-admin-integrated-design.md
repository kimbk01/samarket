### 1.4.1 도메인 간 공통 패턴 (근본 원인)

1. **서버 권한 = "관리자인가"만 확인** — `requireAdminApiUser` 240 / `isRouteAdmin` 60 / `requireAdminPermission` 85 / `requireSuperAdmin` 8 (415 route). 권한 키: business 49 · point 29 · users 23 · settings 2 · reports **1** · dev 1 · **community·trade·chat·ads·notifications 키 없음**. 메뉴 역할 필터는 클라이언트 전용, `viewer` 미생성 (X-10).
2. **감사 기록 불균일** — 변경 export 261개 중 `appendAuditLog` 직접 호출 42개 (일부는 lib 헬퍼 경유, 나머지 ~200 NOT_PROVEN) (X-9).
3. **동시성 계약 불균일** — 주문 개입·신고·쿠폰 일부는 CAS, 게시물 상태·광고 워크스페이스·팝업·레거시 거래 광고는 없음.
4. **브라우저 직접 쓰기** — 거래 주제/카테고리, `/admin/comments` 하드삭제, 신고 목록(anon + `test_users`) (T-15~17).
5. **지표 정의 분산** — 「미처리 거래 신고」 정의 3종(전체 RPC=모든 대상 / 레지스트리=모든 대상 / 거래 대시보드=상품만), 채팅방 신고는 거래·채팅 양쪽 집계, "오늘"=서버 자정 vs UTC vs 마닐라 (X-2, X-5).
6. **딥링크 계약 미소비** — `returnTo` 생산 2곳, 소비 2곳. 파라미터 `store_id`×6 vs `storeId`×3, `target_type`/`targetType`, `orderId`/`order_no`, 상태 필터 이름 4종 (X-7, X-8).
7. **레거시 쓰기 경로 잔존** — 숨김·리다이렉트된 화면 뒤 API 가 살아 있음 (배달 D5, 광고 P-5~7, 거래 광고 T-4, 포인트 조정 2경로 P-15).

`lib/admin/metrics/` 에 지표별 정의를 둔다: `id · domain · 출처(table/RPC) · 필터 · 기간 기준(Manila) · 권한 범위 · 상세 href 빌더`. 전체 관제·도메인 대시보드·Action Center 가 모두 이것만 호출한다. 처리 대기 카운트는 기존 레지스트리를 래핑(재구현 금지).

### 계약 규칙

1. 링크는 `buildAdminHref(target, { filter, returnTo })` 공통 빌더로만 만든다 (기존 `withAdminReturnTo` 확장).
2. 대상 화면은 표준·호환 파라미터를 모두 읽고, 상단 **돌아가기 바**(기존 `AdminOpsCrossLinkBar` 확장)로 `returnTo` 를 소비한다. 목표: 상세·목록 화면 100% (현재 2곳).
3. 대상 화면은 권한이 없으면 `AdminAccessDeniedPanel` + 돌아가기 버튼 (빈 목록과 구분).
4. 링크는 대상 ID 가 없을 때 목록 필터로 대체하지 않는다 — 비활성 + 사유 표기.
