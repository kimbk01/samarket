# CTA CONTRACT

## Primary (action verbs)

검토하기 · 승인 · 거절 · 수정 요청 · 답변하기 · 충전 요청 확인 · 정산 확인 · 신고 검토 · 미납 확인 · 출금 검토

## Secondary (context)

매장 재무 · 회원 정보 · 재무 내역 · 광고 · 관련 기록

## Forbidden as primary

상세 · 원본 · Statement · Finance · Member · Open · 관리

## Ads decision

- Approve: immediate when valid; show why disabled if creative not ready
- Request changes / Reject: open reason panel → confirm
- Never render `reason_required`
