# Community 메신저 1:1 통화 — 모바일 실기기 E2E 체크리스트

**대상:** iOS Safari · iOS PWA(홈 화면) · Android Chrome · Android PWA(설치)  
**범위:** 음성(`voice`) · 영상(`video`) 통화 동일 항목은 한 줄에 묶고, 영상 전용은 표시.

검증 시 **앱/브라우저·OS 버전·기기 모델**을 시트에 적어 두면 재현에 유리하다.

## 1. 마이크 권한

| # | 시나리오 | 음성 | 영상 | 기대 |
|---|----------|:----:|:----:|------|
| 1.1 | 최초 발신 시 권한 요청·허용 | ☐ | ☐ | 마이크 허용 후 조인·링백 가능 |
| 1.2 | 거절 후 재시도 | ☐ | ☐ | OS/브라우저 설정에서 허용 안내 또는 실패 문구 |
| 1.3 | 수락 경로에서 마이크 획득 | ☐ | ☐ | 수락 후 연결·상대 음성 재생 |
| 1.4 | 통화 중 마이크 음소거 on/off | ☐ | ☐ | 상대 청취 변화(또는 UI 상태 일치) |

**플랫폼 메모**

- iOS Safari: 사용자 제스처와 타이밍에 따라 `getUserMedia` 제약이 엄함 → 발신 **허용 후 조인** UX 확인.
- PWA: 독립 창에서도 권한이 **사이트별**로 유지되는지 확인.

## 7. Web Push

**전제:** 브라우저 알림 허용·구독 등록·`WEB_PUSH_ENABLED` 등 서버/환경이 갖춰진 빌드에서만 의미 있음.

| # | 시나리오 | 기대 |
|---|----------|------|
| 7.1 | 탭 백그라운드/다른 앱 전환 중 **수신 통화** 푸시 | 세션 딥링크, 표시 문구(음성/영상) |
| 7.2 | 탭 닫힘(가능한 환경)에서 수신 | 동일 |
| 7.3 | **부재중** 푸시(정책 반영 빌드) | 「부재중 통화」·기록 경로 |
| 7.4 | 발신 취소 시 **기존** 수신 알림만 정리 | 새 시스템 알림 없음 |
| 7.5 | 거절/정상 종료 시 상대에게 **불필요한** 추가 푸시 없음 | 정책과 일치 |

**플랫폼 메모**

- **iOS Safari(일반 탭):** Web Push 제약이 크다. **iOS 16.4+ PWA(홈 화면)** 중심으로 푸시 가능 여부를 구분해 적는다.
- Android: Chrome vs 설치 PWA에서 알림 채널·아이콘 차이 확인.
