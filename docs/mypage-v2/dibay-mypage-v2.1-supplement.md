### 2.2 판단

- Owner 말씀 "스타벅스 계열 그린 = 시그니처" 는 계약과 **일치**한다. 계약값 `#0B421A` 가 바로 "Starbucks-class DIBAY green" 으로 잠겨 있다.
- 문제는 **같은 내정보 화면에 그린이 3가지(`#0B421A` 버튼·토글, `#00704A` 행 아이콘·글자, `#085C3F` 확인 시트)** 섞여 보이는 것이다. 이것이 계약 `:31` "두 번째 브랜드 팔레트 금지" 위반이다.
- 하드코딩 제거 ≠ 브랜드 색 제거. 권고안은 시그니처를 **없애는 것이 아니라 토큰 하나로 모으는 것**이다.

### 2.3 실제 화면 비교

- 세 그린이 섞인 실제 화면 캡처는 이 환경에서 앱을 실행할 수 없어 **NOT_PROVEN**. 구현 승인 시 첫 단계(W0)로 기기 3종에서 "현재 / 통일 후" 화면을 나란히 캡처해 Owner 확인을 받은 뒤 다음 단계로 넘어간다.
