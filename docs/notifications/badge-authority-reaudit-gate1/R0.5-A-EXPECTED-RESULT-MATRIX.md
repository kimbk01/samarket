## 1. Oracle 읽는 법 (잠금)

### 1.1 Task Identity (Wave마다 필수)

| Task | Canonical Identity |
|------|-------------------|
| **N11** | `notification:{eventId}` |
| **C01** | `conversation:{domainIdentityKey}` |

실기 TRACE.md에 **발생 identity 문자열을 그대로** 기록한다.  
Projection이 여러 Surface에 퍼져도 **같은 identity = 같은 Task**.

### 1.2 Controlled baseline · 기호

| 기호 | 의미 |
|------|------|
| `B0` | 이 Task identity의 기여 = 0 |
| `표시` | 같은 identity가 해당 Surface에 **나타남** (digit 기여는 아래) |
| `Δ+1` | **이 identity**로 집합/digit **+1** (다른 Surface의 +1과 **산술 합산 금지**) |
| `Δ+N` | 메시지 unread +N |
| `→0` | 이 identity 기여 제거 |
| `유지` | History 행 유지 · Digit 집합에서는 빠짐 |
| `∪1` | 다 Surface 표시여도 Icon/Native에는 **identity 1회** |

**실측:** `ObservedΔ(identity) = Expected`. 절대 digit만으로 PASS 금지.  
**Runtime PASS ≠ Product PASS.**

### 1.3 Surface ≠ Authority · 중복 계산 금지

Bell · Delivery · FAB · Hub · Row · **App Icon** = Surface.  
동일 Task의 다 Surface 표시는 **Projection의 여러 투영**이지, Icon에 **가산할 항이 아니다**.

### 1.4 Native

`Native = Absolute Echo(App Icon)`. Icon과 동일 identity 기여.
