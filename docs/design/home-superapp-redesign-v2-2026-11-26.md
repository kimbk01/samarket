| 주문 | 진행 중 주문(접수 대기~배달 중). 「주문 {단계 이름} · {남은 시간}」. 단계 이름 = `orderStatusName` 만. 남은 시간 = 조리 중·픽업 대기 전에는 `estimated_ready_at` 까지 「준비 n분」. **「도착 n분」은 배달 예상 값(`checkout_eta_minutes`)이 운영 0건이라 쓰지 않는다** — 그 자리에 매장 이름. 1건 = 주문 상세 / 2건 이상 = 「주문 n건 진행 중」 → 주문 내역 |
| 요청 | 새 API `GET /api/home/my-activity` 1개로 둘 다 (지금 PR 의 주문 요약 + 메신저 목록 2개 요청을 대체 — 메신저 감시 수치 오염·방 저장값 오류(W5) 없앰). Supabase 약 3회(상품 1·주문 1·매장 이름 1) → 예산 표 등록 |
