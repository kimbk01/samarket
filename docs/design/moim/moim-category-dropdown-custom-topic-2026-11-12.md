## 2. 드롭다운 (선택 부분)

- **부품:** 앱에 이미 있는 Owner 승인 선택 칸 `WriteSelectSheetField`(2026-10-28 승인 시안)를 그대로 쓴다.
  - 한 줄 칸에 「고른 값 ▼」을 보여 주고, 누르면 바텀시트 목록이 뜬다.
  - 고른 항목에 ✓ 가 붙고, 누르면 바로 닫힌다.
  - 브라우저 기본 `<select>` 는 Android 기기마다 창이 달라서 쓰지 않는다(부품 주석의 실측).
- **만들기:** 1단계(카테고리만 있던 단계)를 없애고, 2단계(이름·소개) 맨 위에 「카테고리 ▼」 한 줄을 넣는다.
  - **5단계 → 4단계.**
  - 카테고리를 고르지 않으면 「다음」 버튼이 비활성이다(지금 1단계 규칙과 같음).
- **운영 › 정보 수정:** 칩 줄을 같은 드롭다운 한 줄로 바꾼다.
- **바꾸지 않는 것:**
  - 어드민은 이미 한 줄 `<select>` 이다(어드민 화면 규칙).
  - 홈 필터 칩은 선택 칸이 아니라 목록 거르기이고, 이미 한 줄 가로 스와이프다(2단 탭 스와이프 고정 규칙).

```
┌ 카테고리 ───────────────────┐
│ 기타                      ▼ │
└─────────────────────────────┘
┌ 모임 주제 ──────────────────┐   ← 「기타」일 때만 나타남
│ 보드게임                    │
└─────────────────────────────┘
  주제를 직접 적어 주세요 (2~20자)   4/20
```

## 3. 「기타」 → 모임장이 주제를 직접 지정 (아이디어)

### 권장안: 「모임 주제」 한 줄 입력

- **동작:** 드롭다운에서 「기타」를 고르면 바로 아래에 「모임 주제」 입력칸이 나타나고, 모임장이 직접 적는다(예: 보드게임, 러닝 크루, 사진 산책).
  - 2~20자, 필수다.
  - 다른 카테고리를 고르면 입력칸이 사라지고, 저장할 때 주제는 비운다.
- **보이는 곳:**
  - 모임 카드와 모임 공개 페이지에서 「기타」 대신 **주제가 카테고리처럼** 보인다(예: `보드게임 · Makati · 12/30명`).
  - 고객 화면에는 「기타」라는 글자가 나오지 않는다.
- **검색:** 모임 탭 검색어가 모임 이름 **또는 주제**에 맞으면 찾는다. 예: 「보드게임」으로 찾기.
- **잘못된 입력 막기 (서버):**
  1. 운영 정책 금칙어(`moim_policies.banned_words`)를 이름·소개와 같은 방식으로 검사한다.
  2. 주제가 **이미 있는 카테고리 이름과 같으면**(한국어·영어, 대소문자·공백 무시) 저장하지 않는다.
     - 예: 「운동」을 적으면 「운동 카테고리를 골라 주세요」 안내.
     - 그래서 정식 카테고리로 갈 모임이 「기타」에 쌓이지 않는다.
  3. 앞뒤 공백을 지우고, 연속 공백은 하나로 줄인다.
- **어떤 카테고리에서 직접 주제를 받는지:** slug `etc` 를 코드에 고정하지 않는다.
  - 카테고리에 「직접 주제 입력」 표시(`allow_custom_topic`)를 둔다.
  - 지금은 「기타」 하나만 켠다. 어드민 카테고리 관리 화면에 체크 칸을 하나 추가한다.
- **어드민은 지정하지 않고 보기만:**
  - 어드민 모임 목록과 상세에 주제를 보여 주고, 모임 목록 검색에 주제를 포함한다.
  - 수정은 기존 「기본정보 수정」(사유 필수·모임장 알림)에 칸 하나를 더하는 것뿐이다. 신고된 부적절한 주제를 고칠 때만 쓴다.
- **정식 카테고리로 올리는 근거:**
  - 어드민 카테고리 관리 화면 아래에 「직접 입력 주제 많이 쓰인 순」 목록(주제·모임 수, 상위 20)을 보여 준다.
  - 같은 주제가 많이 쌓이면 어드민이 그 이름으로 새 카테고리를 만드는 판단 자료가 된다(만들기는 기존 카테고리 추가 기능).
  - 이미 있는 모임을 새 카테고리로 옮기는 자동 이동은 넣지 않는다(범위 밖).

### 검토했지만 권장하지 않는 것

| 아이디어 | 권장하지 않는 이유 |
|---|---|
| 모든 카테고리에 해시태그 여러 개 | 입력이 늘고 공간이 커져 「공간 최소」와 반대. 태그 정리·금칙 관리 부담 |
| 「기타」 없이 처음부터 자유 입력만 | 홈 필터 칩과 추천이 무너짐(같은 주제가 제각각 이름으로 흩어짐) |
| 입력할 때 동네 다른 모임 주제 자동 추천 | 「보드게임/보드 게임」 같은 표기 통일에는 좋지만 조회 API 가 하나 늘어남. 주제 데이터가 쌓인 뒤 다음 단계로 판단 |
