DIBAY 「모임」 화면 시안 v1

설계 문서 docs/design/moim/moim-design-v1-2026-11-12.md 의 화면 시안입니다. 휴대폰 화면은 360px 기준이고, 어드민 화면은 PC 기준입니다. 사람·모임 이름은 모두 예시입니다. 문구는 구현할 때 i18n 키로 옮깁니다. 숫자 상한(D6)은 아직 정해지지 않아 화면에 넣지 않았습니다.

1. 모임과 다른 채팅의 구분

친구 그룹채팅오픈채팅모임 전체 채팅모임 일정 채팅
만드는 곳메신저메신저모임 개설 시 자동일정 생성 시 자동
들어오기친구 초대·링크검색 후 바로/비밀번호모임 가입 = 자동 입장참여 확정 = 자동 입장
나가기·내보내기방에서방에서모임에서만(방 안에 나가기 메뉴 없음)일정 참여 취소 · 일정 호스트
표시 이름DIBAY 닉네임닉네임·방별 별명모임별 프로필모임별 프로필
기록대화만대화만게시판·일정·앨범은 모임 홈에후기 게시판
목록 표시그룹오픈채팅모임 + 모임 이름일정 + 일정 제목

2. 프로세스 흐름 (요약)

개설

전화 인증 회원→카테고리→이름·소개·사진→동네·정원→가입 방식·질문→운영 규칙 동의→모임 + 기본 게시판 4개 + 전체 채팅방 생성

가입 (바로)

공개 페이지→모임 프로필 확인→멤버 + 채팅방 자동 입장→가입인사 안내·모임장 알림(묶음)

가입 (승인)

질문 답변→신청(대기)→승인권자 알림→승인: 멤버 + 방 입장 + 결과 알림/거절: 결과 알림

초대

링크·QR→공개 페이지→원래 가입 방식대로│친구 직접 초대→수락→운영진 초대는 승인 생략

일정

일정 만들기→일정 채팅방 생성→선착순 참여 / 신청→승인→리마인드→종료·출석→후기 안내

탈퇴·내보내기·차단

탈퇴→모든 모임 방 퇴장 · 다가오는 일정 취소│내보내기(재가입 가능)│차단(재가입·초대·링크 모두 불가)

모임장 위임

직접 위임→상대 수락→교체 + 전체 알림│30일 미접속→운영진 요청→어드민 지정│경고 상태 위임 불가

신고·제재

⋮ 신고→어드민 큐→기각 / 숨김 / 추천 제외 / 경고 / 모임 차단 / 이용 제한→제재 기록 + 신고 처리 + 신고자 알림 한 번에
